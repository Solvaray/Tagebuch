Daten

Verschlüsselt wird auf diesem Gerät, mit demselben Code wie die App-Sperre. Auf dem Server stehen nur unlesbare Blöcke – auch für den Anbieter.
Deine Einträge werden dann auf diesem Gerät verschlüsselt gespeichert und die App fragt beim Öffnen nach dem Code. Es gibt keine Wiederherstellung. Code vergessen heißt Daten weg – es liegt keine Kopie auf einem Server. Vorher exportieren.
Einträge vor dieser Uhrzeit zählen zum Vortag. Ein Eintrag um 00:45 gehört so zum Abend davor statt zu einem neuen Tag – das betrifft auch Tagessummen und konsumfreie Tage.
Alle Daten liegen nur in diesem Browser (localStorage) – es gibt keinen Server, nichts wird hochgeladen. Das heißt aber auch: Cache löschen = Daten weg. Regelmäßig JSON exportieren als Backup.
